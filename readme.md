# C++ Learning Journey
### Hello World Welcome

A hands-on relearning of C++ through building real projects from scratch, all written by hand. The end goal is to build a custom web browser with a built-in content filter.

---

## Goal

Work through 10 console projects, then 2 Qt GUI projects, then begin the browser project.

---
